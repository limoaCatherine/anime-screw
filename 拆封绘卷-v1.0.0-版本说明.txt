拆封绘卷 AnimeScrew v1.0.0 版本说明
==================================
出品：上海盖姆艾尔网络科技有限公司

怎么玩
- 网页版：直接双击 dist/index.html (Chrome / Edge 都行，不用装任何东西)
- Windows 桌面版：单独的压缩包 AnimeScrew_win64.zip，解压后双击 拆封绘卷/拆封绘卷.exe (整个文件夹一起拷走；没有黑色控制台窗口)
  (项目源码包里不带 exe 和运行库，自己打包会生成到 release/拆封绘卷/)
  存档在 %APPDATA%\AnimeScrew\save.json，删掉这个文件就是从头玩
- 没有 exe 的话：装好 Node.js，在项目目录执行 npm install，然后 npm run pack:win

这一版有什么
- 3 幅画 30 关：《雨后的屋顶》《温室》《夜班电车》，每关揭开一块插画碎片，拼齐收进画册
- 障碍：玻璃、锁链、冰冻、钥匙锁、炸弹、隐色、绳吊，外加双层螺丝
- 道具：退一步、加孔、螺丝刀、小锤、换盒；用完可以看激励广告再拿一次 (没配广告位时是 5 秒占位倒计时)
- 失败可以看广告复活，清出 2 个临时孔
- 4 首原创背景音乐 + 揭开插画时的 10 秒小段落；音效全部实时合成
- 4 位角色语音 (VOICEVOX)，设置里有总音量和语音/音效/音乐开关
- 选关地图、画册 (可以放大看、可以分享/保存整幅画)

关卡校验
- npm run verify：Node 里无头跑物理，30 关全部能解，板子都会正常掉出画面
- 报告在 docs/verify_report.txt

已知问题
- 网页版第一次点屏幕之前浏览器不让放声音，所以开场的音乐要点一下才出来 (桌面版没有这个限制)
- 抖音小游戏版还需要把 dist 放进抖音开发者工具的工程里，并在 src/config/GameConfig.js 填广告位 ID
