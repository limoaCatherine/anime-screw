## 1. 一句话定位与差异化卖点

**一句话定位：** 拧下螺丝、拆开封板，把封在画里的女孩一张一张救出来。

| 差异化卖点 | 具体做法 | 对比常规螺丝游戏 |
|---|---|---|
| 拆到最后有画看 | 每关最底层是一块插画碎片，10 关拼成一张完整 CG | 常规产品通关只有"完成"弹窗 |
| 螺丝有角色归属 | 螺丝颜色 = 角色应援色，收纳盒做成角色的小物（发饰盒、乐谱夹等） | 常规为纯色块 |
| 声音做成卖点 | 拧出、落盒、装满、板子落地四类声音单独打磨，连续收纳音阶上行 | 多数产品只做一两种通用音效 |
| 短视频天然素材 | 最后一块板掉落 → 整张画露出，正好是 3~5 秒的录屏高光 | 常规高光只有"清屏" |

## 2. 二次元包装方案

### 2.1 三个备选方向

| | A. 拆封绘卷（推荐） | B. 机巧整备工坊 | C. 后台布景组 |
|---|---|---|---|
| 世界观 | 古董画廊"钉画馆"里的画被封印钉钉死，画中人出不来。玩家是新来的拆封师 | 玩家是机娘整备员，给机娘拆旧装甲、换新部件 | 玩家是偶像团体的舞台工作人员，拆布景换场 |
| 板子是什么 | 画框外的封板：木板、铜板、彩窗玻璃 | 装甲板 | 舞台布景板、灯架 |
| 螺丝是什么 | 封印钉，钉帽刻角色纹章 | 机械螺栓 | 应援灯牌色的舞台螺丝 |
| 拆完露出什么 | 插画碎片（角色日常、场景） | 机娘本体 | 演出场景 |
| 优点 | 揭示感强、和"拼图收集"天然契合；角色不必露肤也有看头 | 机甲受众稳定 | 偶像题材适合换装、应援 |
| 风险 | 需要做足插画量 | **"拆装甲露出本体"容易被理解为擦边，审核风险高** | 偶像题材同质化重，3D 舞台成本高 |
| 结论 | ✅ 推荐 | ❌ 不建议做主线，可做限时活动皮肤 | 备选，作为第二章主题 |

## 3. 核心循环与操作细节

### 3.1 单局循环

观察板子层级 → 点击可拧的螺丝 → 螺丝飞入同色收纳盒（无同色盒则进临时孔）→ 板子失去全部螺丝后掉落 → 露出下层 → 最后一块板落下，露出插画碎片 → 结算。

### 3.2 规则表

| 规则项 | 设计（建议值） | 说明 |
|---|---|---|
| 可点击判定 | 螺丝钉帽不被任何更高层的板子遮挡才能拧 | 被压住的螺丝显示暗色，点击时轻微抖动+"咔"一声提示 |
| 收纳盒 | 屏幕上方同时开放 2 个盒子，每盒 3 个孔位；装满 3 颗同色即合上飞走，队列补下一个 | 第 15 关后部分关卡开放第 3 个盒子位（需看广告解锁，单局有效） |
| 收纳盒颜色顺序 | 由关卡配置决定，玩家能看到"下一个盒子"的颜色 | 给玩家一步预判空间 |
| 临时孔位 | 默认 5 个；道具可 +1；广告复活 +1 | 盒子换色时，临时孔里同色螺丝自动飞入 |
| 板子掉落 | 螺丝全部拆完 → 板子受重力掉出屏幕；只剩 1 颗 → 绕该螺丝旋转下垂 | 下垂可能露出或盖住别的螺丝，这是关卡设计的核心变量 |
| 胜利条件 | 所有板子掉落 | 部分关卡另加"收完所有螺丝" |
| 失败条件 | 临时孔已满，且场上没有可以直接放进当前盒子的可拧螺丝 | 另有：炸弹螺丝步数归零（见 4.2） |
| 步数/时间 | 前 30 关不限时 | 限时只出现在后期每日挑战 |
| 撤销 | 不提供常驻撤销，作为道具 | 避免规则太宽松 |

### 3.3 道具

| 道具 | 效果 | 获取 | 单局上限（建议） |
|---|---|---|---|
| 加孔 | 临时孔 +1（本局有效） | 广告 / 通关奖励 / 礼包 | 2 |
| 螺丝刀 | 直接拆走任意一颗螺丝放进收纳区（无视遮挡） | 广告 / 礼包 | 2 |
| 小锤 | 敲碎一整块板子，板上螺丝全部进临时孔或盒子 | 礼包 / 好感奖励 | 1 |
| 退一步 | 撤回上一次拧螺丝 | 广告 | 3 |
| 换盒 | 当前两个盒子与队列重新洗颜色 | 广告 | 1 |

## 5. 养成 / 收集外循环

## 6. 变现

### 6.1 激励视频点位

| 点位 | 触发时机 | 奖励 | 频控建议 |
|---|---|---|---|
| 失败复活 | 失败弹窗 | 临时孔 +1 并清空 2 颗 / 或螺丝刀 ×1 | 每局 2 次 |
| 局中求助 | 临时孔剩 1 个时弹出提示条（不打断操作） | 加孔 / 螺丝刀 | 每局 1 次 |
| 第 3 盒位 | 进关时 | 本局开放第 3 个收纳盒 | 每局 1 次 |
| 通关翻倍 | 结算 | 金币 ×2（3 倍为限时活动） | 不限，但默认按钮是"直接领取" |
| 碎片提前看 | 章节第 9 关后 | 提前看完整 CG 的模糊预览 | 每章 1 次 |
| 体力补充 | 体力不足 | 体力 +2 | 每日 5 次 |

插屏：前 10 关不出；之后每 3 关最多 1 次，只在结算后、进下一关前出现。Banner：仅大厅底部，局内不放（挡操作、也挡录屏画面）。

### 6.2 IAA / IAP 混合建议

| 项 | 建议 |
|---|---|
| 主模式 | IAA 为主。抖音小游戏用户以免费为主；海外头部产品 Screwdom 的收入结构约 60% IAP / 40% 广告［3］，但国内小游戏环境不同，不能照搬比例 |
| IAP 内容 | 去插屏月卡、道具礼包（加孔 + 螺丝刀 + 小锤）、角色换装礼包、首充 |
| 前提 | IAP 需取得版号并开通抖音虚拟支付；iOS 端支付能力以平台当期规则为准。未拿到版号前先以纯 IAA 上线 |
| 不做 | 抽卡、付费体力、付费复活（只能看广告复活，避免"不充钱过不去"的口碑） |

## 8. 技术实现要点（Cocos Creator 3.8.x）

### 8.1 物理与关节

| 模块 | 方案 |
|---|---|
| 物理引擎 | 2D Box2D；固定步长 1/60 |
| 板子 | `RigidBody2D`（Dynamic）+ `PolygonCollider2D`；多边形顶点从关卡编辑器导出 |
| 螺丝绑定 | 每颗螺丝在所在板子上挂一个 `HingeJoint2D`，锚点连到静态背景体；拧下即销毁关节。开源参考 ScrewCat_PlayableAds 采用同样思路［11］ |
| 层间碰撞 | 每层板子一个碰撞分组，同层碰撞、跨层不碰撞（避免叠放卡死）；掉落出屏后回收 |
| 性能 | 单关刚体 ≤ 40（建议值）；板子落到屏幕外 0.5 秒后直接移除；低端机关闭阴影与粒子 |

### 8.2 层级遮挡判定

- 不用物理射线，用几何判定：螺丝钉帽视为圆，检查所有 `layer > 螺丝所在层` 且未掉落的板子，其当前世界坐标多边形是否与圆相交。
- 只在"有板子移动/旋转"后的稳定帧重算（角速度和线速度低于阈值），结果缓存到螺丝状态上，点击时直接读。
- 板子下垂旋转过程中，螺丝暂不可点，避免玩家抢点导致判定和视觉不一致。

### 8.3 关卡编辑器与可解性

| 项 | 方案 |
|---|---|
| 形态 | Cocos 编辑器扩展面板：在场景里摆板子、画多边形、点孔位、设颜色和障碍，导出 JSON |
| 关卡数据 | `{ boards:[{layer, polygon, material}], screws:[{board, pos, color, obstacle}], boxQueue:[...], cacheSlots:5 }` |
| 颜色校验 | 每种颜色螺丝数必须是 3 的倍数，导出时自动检查 |
| 可解性 | 无头模式跑同一套物理（固定步长 + 固定随机种子），用贪心 + 回溯机器人自动打 200 次（建议值），输出通关率、平均剩余临时孔，作为难度参考 |
| 插画碎片 | 关卡底图引用画册碎片 ID，编辑器里直接预览"拆完后的画面" |

### 8.4 音频系统（AudioSystem）

见第 9 节。代码层面：统一的 `AudioSystem` 单例负责语音队列、BGM 播放与压低、短音效实时合成和限频；抖音端优先用平台提供的 WebAudio 能力（`tt.createWebAudioContext`，以真机兼容性为准），不支持的机型回退到预渲染的短样本。

### 8.5 成品打包

除抖音小游戏包外，另出两个对内/对外演示用的成品，统一放在 `smallgame\AnimeScrew`：

| 产物 | 路径 | 说明 |
|---|---|---|
| 网页版 | `smallgame\AnimeScrew\dist\index.html` | Cocos Web Mobile 构建，可直接本地或静态服务器打开 |
| PC 版 | `smallgame\AnimeScrew\` 下的 Electron `.exe` | 套网页版构建；存档写在 `%APPDATA%`（例如 `%APPDATA%\AnimeScrew\save.json`），卸载/覆盖安装不丢档 |
| 抖音版 | 抖音开发者工具上传 | 存档用 `tt.setStorage` + 云端同步（V1.1） |

三端共用一套存档结构，平台差异由 `SaveAdapter` 封装。

## 9. 音效设计（对齐公司合成类游戏音频管线）

### 9.1 总体规范

| 项 | 标准 |
|---|---|
| 语音响度 | -20 LUFS（积分响度） |
| BGM 响度 | -22 LUFS |
| 默认音量 | 语音 0.3｜音效 0.12｜BGM 0.15 |
| 主音量 | 设置页一个主音量滑条，乘到所有通道上；另保留语音/音效/BGM 三个分项开关 |
| 语音时 BGM 压低 | 播语音时 BGM 平滑降到当前值 ×0.55，语音结束后平滑恢复（过渡时长建议 150ms 降 / 400ms 升） |
| 语音并发 | 同时只播一句；两句之间冷却 0.6 秒；冲突时优先级高的先说，低优先级的直接丢弃不排队 |
| BGM 来源 | 预先编曲、导出的成品音频文件（不用合成器实时生成）；进分包，按章节切换 |
| 短音效来源 | 在 AudioSystem 里用 WebAudio 实时合成（振荡器 + 噪声 + 包络 + 滤波），不占包体 |
| 限频 | 同一音效 60ms 内最多触发 1 次，同帧同类最多 2 个声部（建议值） |

**语音优先级：**

| 优先级 | 类型 | 示例 |
|---|---|---|
| 1（最高） | 剧情 / CG 揭开 | "哎？外面的天……是亮的？" |
| 2 | 失败、复活 | "卡住了？我帮你记着位置，再来一次。" |
| 3 | 关卡开场 / 通关 | "先拧最上面那颗。" |
| 4（最低） | 局内提示 | "旁边那排快放不下了。" |

### 9.2 配音：VOICEVOX + 署名面板

| 项 | 规范 |
|---|---|
| 工具 | VOICEVOX 生成日语语音，中文字幕显示；每位角色固定一个音色 |
| 选角 | 立项时逐个核对所选音色的个别利用规约：多数音色允许商用但必须署名；东北企划系角色禁止用于政治、成人内容；部分音色禁止作为原创角色配音或有额外限制；"青山龍星"等音色企业使用需事先申请［12］［13］。**法务确认通过后再进制作** |
| 署名 | 设置页 →"致谢"面板，逐条列出 `VOICEVOX:角色名`；抖音详情页简介同步写一份 |
| 数量 | 角色语音每关只说一两句；MVP 合计约 80~120 句（估计） |
| 去机器感 | ① 每句手调音高曲线，句尾按情绪下坠或上扬，不用默认平直语调；② 台词口语化，带"哎""……行""嗯？"这类语气词；③ 句首/句间混入真实气声样本（吸气、轻叹）；④ 后期统一加一个"小房间"短混响（画廊室内感），干湿比低；⑤ 同一句录 2 个版本随机播 |
| 处理链 | VOICEVOX 导出 → 手调 → 降噪/去齿音 → 加气声 → 混响 → 响度归一到 -20 LUFS → 峰值 ≤ -1 dBTP → 导出 ogg/mp3 |

### 9.3 核心 ASMR 音效细化

ASMR 是核心卖点，以下四类声音单独打磨，每类都要求"音色固定、细节随机"：同一类声音听起来是同一种材质，但连续听不会像复读。

| 音效 | 质感目标 | 合成要点 | 随机化 |
|---|---|---|---|
| 拧螺丝（拧出） | 金属螺纹摩擦的"嗞—嗞"两三下，最后一声"啵"松脱 | 3 段短促带通噪声（中心频率 2~4kHz）模拟螺纹咬合，间隔 40~60ms；尾部一个短正弦"啵"（衰减 80ms） | 噪声中心频率 ±8%；段间隔 ±10ms；"啵"音高 ±1 个半音 |
| 被遮挡拧不动 | 闷的"咔"，像卡住 | 低通噪声 + 200Hz 短冲击 | 音高 ±0.5 半音 |
| 落入收纳盒 | 小金属件掉进木盒的"叮咚"，先清脆后带木头闷响 | 高频正弦 + 金属泛音（非整数倍谐波）冲击，叠一个低通木质"咚"（150~250Hz） | **音高走连击音阶，见 9.4**；泛音比例小幅随机 |
| 进临时孔 | 比进盒子更"空"，提醒这是暂存 | 同上但去掉木质低频，加短延迟 | 音高固定在音阶低位，不参与连击 |
| 收纳盒装满 | 盒盖"啪"合上 + 一个短和弦上行 | 噪声冲击做盒盖；后接五声音阶三音快速琶音（每音 50ms） | 琶音起始音随当前连击层级上移 |
| 板子掉落碰撞 | 按材质区分：木板"空咚"、铜板"铛"、玻璃"叮—"带碎响 | 木：低通噪声 + 120Hz 衰减；铜：多个非谐波正弦衰减 600ms；玻璃：高频正弦 + 少量高通噪声 | 依据落地速度调音量和亮度（速度大 → 更响、截止频率更高）；音高 ±1 半音 |
| CG 揭开 | 轻的纸张展开声 + BGM 衔接 | 粉红噪声扫频 | 不随机，做成标志音 |

### 9.4 连击音阶设计

- **音阶：** 五声音阶（宫商角徵羽，以 C 为宫：C D E G A），任意连续组合都不会刺耳。
- **规则：** 1.2 秒内连续把螺丝收进盒子（不含临时孔），每次音高上升一级；第 5 次之后进入下一个八度；最高升到第 10 级后保持在顶部不再上升。
- **断连：** 超过 1.2 秒没有收纳、或螺丝进了临时孔，连击清零回到起始音。
- **盒子装满：** 琶音从当前连击音开始往上走三个音，作为这一串的"句号"。
- **同屏多颗：** 道具一次收多颗时，按 50ms 间隔依次发声，仍走上行音阶，配合限频规则不叠爆。

## 11. 风险点

| 风险 | 说明 | 应对 |
|---|---|---|
| 玩法同质化 | 螺丝品类竞品极多，买量成本高 | 差异化靠题材 + 收集 + 声音；买量素材主打"拆到最后露出画" |
| 版权：竞品 | 玩法规则一般不受著作权保护，但 UI 布局、美术、关卡造型、名称可能构成侵权 | 不使用"Screw Jam"等竞品名称和图标风格；关卡全部原创；UI 自行设计 |
| 版权：开源代码 | 参考的开源项目许可证需逐个确认，部分仓库未声明许可证 | 只参考思路，不直接拷贝代码；确需引用时法务核对许可证 |
| 版权：语音 | VOICEVOX 各音色规约不同，有的禁止原创角色配音、有的企业需申请 | 选角阶段法务逐条确认，致谢面板完整署名 |
| 版权：AI 美术 | AI 生成内容的版权归属存在不确定性，平台可能要求标注 | 关键 CG 以人工绘制/深度人工修改为主，保留过程稿 |
| 立绘审核尺度 | "拆开露出角色"天然容易被往擦边方向理解 | 选用"拆封画框"而非"拆衣/拆装甲"；服装完整；提审前按平台规范自查 |
| 版号 | 无版号不能开 IAP | 首发纯 IAA，版号并行申请 |
| 物理稳定性 | 不同机型浮点差异可能导致下垂角度不同，影响可解性 | 固定步长；遮挡判定只在稳定帧算；关卡留余量，不依赖精确角度 |
| 低端机性能 | 刚体多、实时合成音效占 CPU | 刚体上限、出屏回收；音效限频 + 回退预渲染样本 |
| 广告体验 | 频次过高导致差评和投诉 | 前 10 关不出插屏，局内不放 Banner，复活只给广告不逼付费 |
