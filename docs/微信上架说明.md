# 《拆封绘卷》微信小游戏上架说明

出品：狸猫　·　游戏版本 v1.2.0　·　整理日期 2026-10-11

这份说明是给你自己的微信公众平台账号用的，按顺序做即可。文中规则和链接都来自 2026-10-11 查到的微信开放文档（developers.weixin.qq.com）和腾讯客服页（kf.qq.com）。平台规则会变，提审前请再点开链接确认一遍。

> **重要：「狸猫」只是出品署名，不是法律主体。**
> 下面这些都必须用**你在微信公众平台注册并认证的真实公司主体（公司全称）**，并且彼此一致：
> - 小游戏账号的主体信息与微信认证；
> - 软著的著作权人（如果提交软著）；
> - 《游戏自审自查报告》的落款与公章；
> - 《用户隐私保护指引》里的主体与联系方式；
> - 小程序备案（ICP）的主办者。
>
> 「狸猫」只出现在游戏画面、介绍文案等「出品：狸猫」的署名位置，不能用作软著著作权人、自审报告落款或隐私主体。
> 官方的常见驳回原因里就有「游戏名称、签署主体等与当前的游戏不一致」（[资质审核(IAA)](https://developers.weixin.qq.com/minigame/introduction/guide/zzsh-iaa.html)）。

微信小游戏工程就在 `拆封绘卷\微信小游戏\` 文件夹里，下面简称「工程」。里面的 `game.json`、`project.config.json`、`game.js` 都已生成好，可以直接导入微信开发者工具。

## 0. 先看结论：上线要准备什么

本游戏只靠激励视频广告变现、**没有内购**，在微信叫 **IAA 游戏**，走「IAA 游戏发布指引」：注册账号 → 名称/简称/头像、类目 → 微信认证、适龄提示、资质审核 → 版本审核 → 小游戏备案 → 小程序备案 → 发布。官方预计 IAA 游戏整体需要 **13～37 个工作日**，多个环节可以并行（[小游戏接入指南](https://developers.weixin.qq.com/minigame/introduction/guide/)、[IAA 游戏发布指引](https://developers.weixin.qq.com/minigame/introduction/guide/iaa.html)）。

| 事项 | 要不要 | 说明 |
|---|---|---|
| 小游戏账号（企业主体）| 必须 | 在 mp.weixin.qq.com 注册，注册时选「游戏」类目，管理员用手机微信扫码 |
| 微信认证 | 必须 | 「企业主体必须进行微信认证才能提交小程序备案」，1～3 个工作日 |
| 游戏版号 | **本游戏不需要** | IAA 游戏在资质管理里选「**情况二：小游戏当前及未来均不需要开通虚拟支付**」，走无版号的「小游戏备案」（主管部门前置审批）。以后要加内购，再补版号、做变更备案 |
| 软著 | 一般不强制，建议有 | IAA 游戏只有两种情况必须交软著：①游戏名称含英文或「软件」字样；②涉及品牌、公众人物合作。「拆封绘卷」两种都不属于。但抖音版必须有软著，建议同一份软著（著作权人 = 公司主体）两边都用 |
| 游戏自审自查报告 | 必须 | 提交版本审核时必填，企业主体盖公司公章，图片格式，≤5 MB（模板见第 6 节）|
| 适龄提示 | 必须 | 「设置 → 基础设置 → 基本信息 → 适龄提示」，建议 **8+**（理由见第 6 节）；没设会卡备案进度 |
| 用户隐私保护指引 | 必须 | 本游戏不收集任何个人信息 → 选「确认承诺未处理用户任何信息」即可（第 6 节）|
| 小游戏备案 | 必须（无版号）| 平台初审 1～2 个工作日 + 主管部门 10～20 个工作日。**提交后不能再改名称和主体** |
| 小程序备案（ICP）| 必须 | IAA 选「情况二」，约 10～30 个工作日；拿到备案号后才能发布 |
| 流量主 + 激励视频广告位 | 首发不需要，上线后再开 | 流量主开通条件是「累计独立访客（UV）> 500」等（第 8 节），新游戏上线前达不到。所以**首发版不填广告位 ID**，游戏里会自动隐藏所有「看广告」按钮：<br>• 失败后每关有 1 次免费「再试一次」；<br>• 道具用完后，每种每天可免费领 1 个；<br>• 不出现「多一个盒子」广告位。<br>开通流量主后把广告位 ID 填进去再发一版，激励视频自动恢复（第 4 节）|

## 1. 注册小游戏账号（公司主体 + 手机微信扫码）

1. 打开 <https://mp.weixin.qq.com>，点「立即注册 / 前往注册」，账号类型选「**小程序**」（小游戏是小程序的一个类目）。
   - 官方：[小游戏账号注册](https://developers.weixin.qq.com/minigame/introduction/guide/register.html) → [小程序注册流程](https://kf.qq.com/faq/170109iQBJ3Q170109JbQfiu.html)
2. 按注册流程填写邮箱（需要一个**没有注册过公众平台**的邮箱）、激活，然后「信息登记」：
   - 主体类型选「**企业**」，填公司全称、统一社会信用代码；
   - 管理员身份信息 + 手机号，并用**管理员本人的手机微信扫码**确认（之后很多操作，如添加类目，都要管理员扫码）。
3. **类目**：注册时勾选「游戏」。官方说明：一级类目「游戏」不能修改，选错只能重新注册（[类目设置](https://developers.weixin.qq.com/minigame/introduction/guide/type.html)）。
4. 同一主体能注册的小程序数量有上限，见 [注册上限和绑定上限](https://developers.weixin.qq.com/community/minigame/doc/00004263b00290c615a3ae75e66008)。

## 2. 拿到 AppID，完善名称 / 头像 / 类目 / 认证

1. **AppID**：登录 MP 后台 →「开发 → 开发管理 → 开发设置」里能看到 AppID（`wx` 开头）。把它填进：
   - `微信小游戏\project.config.json` 的 `"appid"`（或者导入开发者工具时直接填，工具会写回这个文件）；
   - 源码里的 `wechat/wechat.config.json`（以后用 `npm run build:wechat` 重新构建时会带上）。
2. **名称、简称、头像、介绍**：首页「小程序信息 → 前往设置」（[名称、简称 & 图标设置](https://developers.weixin.qq.com/minigame/introduction/guide/name.html)，命名规范见 [小程序名称、简称设置规范](https://kf.qq.com/faq/170109umMvm6170109MZNnYV.html)）。
   - 名称：`拆封绘卷`。
   - 头像：`docs/store/icon_512.png`。
   - 介绍：用 `docs/store/商店简介.md` 里的「简介」。
   - 小游戏备案提交后就不能再改名称和主体了，所以名称请在这一步定好。
3. **类目**：首页「小程序类目 → 去补充 → 添加类目」，管理员扫码验证。
   - 二级类目建议选「**休闲**」：玩法是拧螺丝解谜，没有对战，也没有角色养成。官方提醒：二级类目和游戏内容不符会在提审时被驳回；发布后二级类目不能再改。
   - 三级类目在「设置 → 游戏设置 → 资质管理」里选，选与玩法最接近的益智/解谜类，以下拉框里实际的名称为准。
   - **不要选「文化互动」**：选了之后不能再改，也不能开虚拟支付。
4. **微信认证**：「设置 → 微信认证」，非个人主体按 [申请流程指引（非个人）](https://kf.qq.com/faq/170109F7ZVzq170109MnQRNN.html) 准备 [所需资料](https://kf.qq.com/faq/1701097zqURN170109VRFjYR.html)，1～3 个工作日（[微信认证](https://developers.weixin.qq.com/minigame/introduction/guide/wxrz.html)）。认证费用以页面提示为准。

## 3. 微信开发者工具：安装、扫码登录、导入、真机预览、上传

> 交付时（2026-10-11）检查过你的电脑：**还没有安装微信开发者工具**（只装了微信客户端），需要先装。

1. **安装**：打开 [微信开发者工具下载页](https://developers.weixin.qq.com/minigame/dev/devtools/download.html)（会跳到 [稳定版下载](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)），下载 **Windows 64 位稳定版**，然后安装。
2. **扫码登录**：启动后用**已绑定为该小游戏「开发者」或管理员的微信**扫码。
   - 其他人要参与开发或预览，先在 MP 后台「管理 → 成员管理」里把他加为开发者或体验者。
3. **导入工程**：
   - 选「小游戏」→「导入」；
   - 目录选 `拆封绘卷\微信小游戏`；
   - AppID 填你的 AppID（暂时没有可以选「测试号」，只能本地调试，不能上传）；
   - 工具会读 `project.config.json`：`compileType` 为 `minigame`，这是官方文档写明的有效值（[项目配置文件](https://developers.weixin.qq.com/minigame/dev/devtools/projectconfig.html)）。
   - 导入后模拟器里应能看到加载条 → 主界面，点「开拆」可以玩。
4. **真机预览**：工具栏点「预览」生成二维码，用手机微信扫码，在真机上玩。
   - 也可以点「真机调试」，看真机日志。
   - 重点检查：声音（静音键开/关都试试）、BGM 循环点有没有空白、刘海屏和右上角胶囊按钮有没有挡住界面、转发菜单。
5. **上传**：工具栏点「上传」，填版本号 `1.2.0` 和备注。上传后 MP 后台「管理 → 版本管理」会出现「开发版本」。
   - 命令行上传（官方 [命令行调用](https://developers.weixin.qq.com/minigame/dev/devtools/cli.html)）：
     - 先在工具「设置 → 安全设置」里**开启服务端口**；
     - 命令行程序是安装目录下的 `cli.bat`；
     - 上传前必须处于登录状态（可以先运行 `cli login`）。

   ```powershell
   # PowerShell 里执行（路径按你的实际安装目录改）
   & "C:\Program Files (x86)\Tencent\微信web开发者工具\cli.bat" upload --project "<拆封绘卷所在目录>\拆封绘卷\微信小游戏" -v 1.2.0 -d "v1.2.0 首发"
   # 可选：-i info.json 把代码包 / 分包大小写到文件；预览二维码：cli preview --project <同上>
   ```

## 4. 激励视频广告位（以后开通流量主再做）

- **唯一要改的配置文件**是 `微信小游戏\game-config.js`（源码里对应 `wechat/wechat.config.json`）：

  ```js
  module.exports = {
    appid: "YOUR_APPID",
    rewardedAdUnitId: "YOUR_REWARDED_AD_UNIT_ID",   // ← 换成 adunit-xxxxxxxx
    shareTitle: "拧下螺丝，把画一块块拆出来",
    shareImageUrlId: "",
  };
  ```

- `rewardedAdUnitId` 保持 `YOUR_` 开头或留空，就是首发的**无广告版**，规则同第 0 节表格里的流量主一行。
- 填上真实 ID（MP 后台「流量主 → 广告管理 → 新建激励视频广告位」）后重新上传、提审。游戏会用 `wx.createRewardedVideoAd({ adUnitId })` 创建广告，`onClose` 回调里 `isEnded === true`（完整看完）才发奖励。所有「看广告」入口会自动出现：
  - 失败面板的「看个广告，多开一个孔」（每关最多 2 次）；
  - 道具用完时的「看广告领道具」；
  - 「多一个盒子」广告位。

## 5. 游戏里已经接好的微信能力（全部按官方文档核对）

| 能力 | 用到的接口 | 说明 |
|---|---|---|
| 画布 | `wx.createCanvas()`、`wx.createImage()` | 第一次 createCanvas 是上屏画布，之后是离屏画布 |
| 触摸 | `wx.onTouchStart/Move/End/Cancel` | Touch 用 `identifier`、`clientX/clientY` |
| 屏幕适配 | `wx.getWindowInfo()`（低版本退回 `wx.getSystemInfoSync()`）、`wx.getMenuButtonBoundingClientRect()` | 9:16 画面放进安全区，避开刘海屏和右上角胶囊按钮 |
| 存档 | `wx.setStorageSync` / `wx.getStorageSync` | key `animeScrew.save.v1` |
| 音频 | `wx.createInnerAudioContext()` | 全部 mp3（iOS 不支持 ogg）。语音 -20.6 LUFS，BGM -22.4 LUFS。BGM 循环用两路 InnerAudioContext 接力 + 首尾垫片，循环点没有 mp3 编码空白（和抖音版同一套，见 `douyin/README.md`） |
| 前后台 | `wx.onShow` / `wx.onHide` | 切后台时暂停主循环、音乐、语音 |
| 分包 | `wx.loadSubpackage({ name })` | voice / bgm / cg 三个普通分包，启动时加载 |
| 激励视频 | `wx.createRewardedVideoAd` | 见第 4 节 |
| 转发 | `wx.showShareMenu({ menus: ['shareAppMessage'] })` + `wx.onShareAppMessage`（右上角菜单）；`wx.shareAppMessage`（过关后「给朋友看看这幅画」）| 转发图 `assets/share.jpg` 是 500×400，官方要求 5:4 |
| 不提供 | — | 抖音专有的侧边栏复访礼包、通关录屏分享，在微信版里自动隐藏 |

## 6. 提审前要填的资料

1. **资质审核（IAA）**：「设置 → 游戏设置 → 资质管理 → 前往管理」，或首页「小程序备案 → 小游戏备案&发布流程指引 → 资质提交」。
   - 选「情况二」，三级类目选与玩法一致的，「不申请支付资质」。
   - 有软著就上传（著作权人与主体一致）。
   - 1～3 个自然日。官方：[资质审核(IAA)](https://developers.weixin.qq.com/minigame/introduction/guide/zzsh-iaa.html)，材料规范：[小游戏资质提交审核指引](https://developers.weixin.qq.com/community/minigame/doc/0008282466cfb096eb679e9b551408)。
2. **适龄提示**：「设置 → 基础设置 → 基本信息 → 适龄提示」（[适龄提示设置指引](https://developers.weixin.qq.com/minigame/introduction/guide/slts.html)），建议 **8+**。理由对照官方 8+ 描述：
   - 画面是卡通/手绘风格；
   - 没有对抗和竞技；
   - 没有陌生人自由交流的社交系统；
   - 角色和故事都很简单友好。
3. **用户隐私保护指引**：「设置 → 基本设置 → 服务内容声明 → 用户隐私保护指引」（[小游戏隐私合规开发指南](https://developers.weixin.qq.com/minigame/dev/guide/open-ability/privacy)）。
   - 本游戏**不调用任何涉及个人信息的接口**：不获取头像昵称、位置、相册、剪贴板、麦克风等，存档只在本机。所以选「**确认承诺未处理用户任何信息**」即可，不用接 `wx.requirePrivacyAuthorize`。
   - 开通流量主后，广告由微信平台提供；具体以页面提示为准。
   - `docs/store/隐私协议.md` 是我们起草的补充说明（主体处请填公司全称），可以作为对外文本。
4. **游戏自审自查报告**：提交版本审核时必填。企业主体**盖公司公章**，上传 jpg/png，≤5 MB（[官方回复](https://developers.weixin.qq.com/community/develop/doc/0000026f4c4548ca35198fbd851800)，[发布流程](https://developers.weixin.qq.com/minigame/introduction/gamemaker/minigame/release)）。可按下面的模板改写后打印、盖章、拍照（没有软著就删掉软著那一句）：

   > 《拆封绘卷》游戏自审自查报告
   >
   > 《拆封绘卷》是【公司全称】自主研发的休闲益智类手机小游戏（【如有软著：已取得国家版权局颁发的《计算机软件著作权登记证书》，登记号 软著登字第 XXXXXXX 号】）。
   >

   >
   > 一、不含违反宪法确定的基本原则，危害国家统一、主权和领土完整的内容；

   - 宣传图可以用 `docs/store/` 里的截图。截图是在广告位为空的配置下截的，没有任何「看广告」按钮，和首发版一致。
   - 正常 1 个自然日。
6. **小游戏备案**：「账号设置 → 小程序备案 → 去完善 → 小游戏备案 → 前往提交」（[小游戏备案](https://developers.weixin.qq.com/minigame/introduction/guide/nrjs.html)）。
   - 如实介绍场景、玩法、功能，并上传截图。
   - 主管部门审批期间**不要改名称或主体**，否则会被驳回、重新排队。
7. **小程序备案（ICP）**：小游戏备案通过后，在「小程序备案」按页面指引完成（[小程序备案](https://developers.weixin.qq.com/minigame/introduction/guide/xcxba.html)，[操作指引](https://developers.weixin.qq.com/minigame/product/record/guidelines.html)）。主办者 = 公司主体。
8. **发布**：版本审核通过 + 小程序备案完成（拿到备案号）后，在「版本管理 → 审核版本 → 提交发布」，选全量发布。

## 7. 包体

| | 大小 | 官方上限 |
|---|---|---|
| 主包（代码 + 头像 + 音效 + 转发图）| 1.02 MB | 4 MB |
| 分包 sub_voice（语音 36 句）| 0.43 MB | 普通分包单个不限 |
| 分包 sub_bgm（BGM 5 首）| 3.58 MB | 普通分包单个不限 |
| 分包 sub_cg（插画 3 幅）| 0.41 MB | 普通分包单个不限 |
| 整包（主包 + 分包）| 5.44 MB | 30 MB |

- 上限出处：[分包加载](https://developers.weixin.qq.com/minigame/dev/guide/base-ability/subPackage/useSubPackage.html)，「整个小游戏所有分包大小不超过 30M，主包不超过 4M，单个普通分包不限制大小，单个独立分包不超过 4M」。本作不用独立分包。
- 每次构建都会生成 `wechat/size-report.txt`；超限时构建直接失败。
- 预览、真机调试时，如果工具提示包太大，可以在「详情 → 本地设置」里打开 `bigPackageSizeSupport`。不过本作远没到上限。

## 8. 流量主开通门槛（上线后）

官方 [广告 — 开通条件](https://developers.weixin.qq.com/minigame/introduction/commercialization/ad/)，满足任一条件即可：

1. 小程序**累计独立访客（UV）> 500**，且无刷粉行为、未曾有严重违规记录；
2. 开通内置游戏圈并产生有效活跃，且发布官方帖 5 篇；
3. 同公司主体名下已有小程序开通了流量主、从昨日起持续 1 个季度有变现、且无流量主违规记录 → 可直接开通。

补充说明：

- 开通入口：MP 后台「功能 → 流量主」（也有写作「推广 → 流量主」的）。
- 资格次日刷新：满足条件后第二天再试。
- 开通后补充财务资料，再新建激励视频广告位，把 ID 填进第 4 节的配置。

## 9. 重新构建 / 自测（给开发者）

```bash
npm install
npm run render:sfx        # 预渲染音效 mp3 (assets/sfx，已经有就不用跑)
npm run build:wechat      # → wechat/dist/ (交付时就是「微信小游戏」文件夹)，同时生成 wechat/size-report.txt、bgm-loop-report.txt
npm run test:wechat       # 无头 Chromium + wx 模拟器 (tools/lib/wx-mock.js) 用触摸把第 1 关玩一遍 → wechat/harness-report.txt
```

`wx-mock.js` 只提供上面第 5 节核对过的 `wx.*` 接口：

- 屏蔽了 window、document、Image、Audio、localStorage 等浏览器全局，`tt` 为 undefined；
- 游戏访问任何未核对的接口，或在分包加载前访问分包资源，都会被判为失败。

当前结果：**16/16 通过**，覆盖以下内容：

- 启动和分包；
- 触摸玩通第 1 关；
- 转发（游戏内 + 右上角菜单）；
- 无广告位时的免费「再试一次」；
- 填 ID 后 `isEnded` 看完发奖、中途关闭不发奖；
- 没有侧边栏礼包；
- 前后台；
- 音效、语音、音乐；
- LoopTrack；
- 存档；
- 没有未核对接口，也没有运行时错误。

## 10. 常见问题

- **导入时提示 compileType 不对、或者被识别成小程序？** 当前官方文档写的有效值是 `minigame`。如果你装的工具版本比较旧，把 `project.config.json` 里的 `"compileType"` 改成 `"game"` 再导入试试。
- **为什么没有「看广告」按钮？** 首发版广告位 ID 为空时就是这样设计的（第 0、4 节），不是 bug。
- **能和抖音版共用软著吗？** 可以，前提是软件名称「拆封绘卷」和著作权人（公司主体）都一致。
- **能不能用「狸猫」做主体？** 不能。「狸猫」只是出品署名（见开头说明）。
