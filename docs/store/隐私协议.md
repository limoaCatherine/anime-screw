## 二、本游戏不收集的信息
本游戏**没有**以下功能：
- 账号注册或登录；
- 自建服务器，也不向开发者服务器上传任何数据；
- 聊天、评论、自由文字输入；
- 内购付费；
- 读取通讯录、位置、相册、麦克风、摄像头。

因此，我们**不收集**你的姓名、手机号、身份证号、位置、设备标识等个人信息。

## 三、只保存在你手机本地的数据
为了记住游戏进度，本游戏用抖音小游戏提供的本地存储接口（tt.setStorageSync / tt.getStorageSync），在你的设备上保存这些内容：
- 关卡进度和已解锁的插画碎片；
- 道具数量；
- 音量、语音、字幕等设置；
- 每日侧边栏奖励的领取日期。

这些数据只存在你设备上的本游戏存储空间里，不会上传给我们。卸载抖音或清除小游戏缓存后会一起删除。

## 四、由抖音平台提供的功能
以下功能由抖音平台的接口提供，相关数据由抖音平台按其隐私政策处理，本游戏拿不到你的个人信息：
1. **激励视频广告**（tt.createRewardedVideoAd）：首发版本不含广告。以后的版本开通后，只在你主动点「看广告」时播放。广告的展示、统计和反作弊由抖音平台及其广告服务完成。本游戏只收到「是否看完」的结果，用来发放道具或复活。
2. **游戏录屏与分享**（tt.getGameRecorderManager、tt.shareAppMessage）：
   - 录屏只录本游戏的画面，视频暂存在本机；
   - 只有你在通关后点「分享通关录屏」并在抖音的发布页确认，视频才会发布；
   - 不点分享，录屏不会离开你的设备。
3. **分享给朋友**（tt.shareAppMessage）：在你主动点击后发起。
4. **首页侧边栏**（tt.checkScene、tt.navigateToScene）：用来判断你是不是从抖音首页侧边栏进入的，并发放每日奖励，不涉及个人信息。
