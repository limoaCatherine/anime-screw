# 《拆封绘卷》抖音小游戏上架说明

出品：狸猫　·　游戏版本 v1.2.0　·　整理日期 2026-10-11

这份说明是给你自己的抖音开放平台账号用的，按顺序做即可。文中规则和链接都来自 2026-10-11 查到的抖音开放平台官方文档。平台规则会变，提审前请再点开链接确认一遍。

> **重要：「狸猫」只是出品署名，不是法律主体。**
> 下面这些都必须用**你在抖音开放平台认证的真实法律主体**（个人实名或公司全称），并且彼此一致：
> - 开放平台的主体认证；
> - 软著的著作权人；
> - 隐私政策里的主体与联系方式；
> - ICP 核准的主办者。
>
> 「狸猫」只出现在游戏画面、商店文案等「出品：狸猫」的署名位置，不能用作软著著作权人或隐私政策主体。

抖音小游戏工程就在 `拆封绘卷\抖音小游戏\` 文件夹里，下面简称「工程」。里面的 `game.json`、`project.config.json`、`game.js` 都已经生成好，可以直接导入抖音开发者工具。

## 0. 先看结论：上线要准备什么

| 事项 | 要不要 | 说明 |
|---|---|---|
| 抖音开放平台账号 + 主体认证 | 必须 | 个人或企业都可以；不做主体认证就不能创建小游戏 |
| 计算机软件著作权登记证书（软著） | 必须 | 软件名称要与小游戏名称一致（「拆封绘卷」），著作权人要与平台主体一致，不一致就要附盖章或签字的授权书 |
| 游戏版号（广电总局版号批文） | 本游戏不需要 | 版号只在开通**内购（游戏内付费）**时才要。本游戏只有激励视频广告，没有内购，走「无版号」流程：小游戏备案 → ICP 核准 |
| 小游戏备案 | 必须（无版号） | 基础信息审核通过，并且有一个版本提审通过后，由平台**自动申报**，不用你手动提交 |
| ICP 核准 | 必须 | 小游戏备案通过后入口开放，自己填写并完成人脸核验；拿到 ICP 核准号后才能上架 |
| 隐私政策 | 必须展示 | 平台为小游戏提供统一的隐私政策（名称、主体自动带入，不能自定义编辑）。我们另外起草了一份补充说明，放在 `docs/store/隐私协议.md`，供核对内容和对外展示 |
| 适龄提示 | 必须 | 控制台「设置-基础设置-小游戏适龄提示」里申报。建议选 **8+**，理由见第 7 节 |
| 侧边栏复访 | 必须接入 | 平台从 2023-11-24 起把它列为「必接审核」项。**游戏里已经接好**（主界面左上角「入口有奖」礼包） |
| 客服能力、敏感词 | 不需要 | 客服只要求内购游戏接；敏感词只要求有用户自由输入的游戏接。本游戏两者都没有 |
| 流量主 + 激励视频广告位 | 首发不需要，上线后再开 | 流量主一般要求游戏先上线。所以**首发版不填广告位 ID**，游戏里会自动隐藏所有「看广告」按钮：<br>• 失败后每关有 1 次免费「再试一次」；<br>• 道具用完后，每种每天可免费领 1 个；<br>• 不出现「多一个盒子」广告位。<br>上线后开通流量主，把广告位 ID 填进去再发一版，激励视频会自动恢复（见第 3、4 节） |

## 1. 注册并登录抖音开放平台

1. 打开 <https://developer.open-douyin.com/>，点右上角「登录」，然后注册账号。可以用手机号、邮箱或抖音号注册，前提是这个号码或账号没在开放平台注册过。
2. 登录后按提示完成**主体认证**（个人主体或企业主体），企业主体还要做对公验证。没有主体认证就不能创建小游戏。
   - 官方说明：[注册与入驻](https://developer.open-douyin.com/docs/resource/zh-CN/mini-game/guide/minigame/register)
3. 提醒：游戏里署名为「出品：狸猫」。平台上的**主体名称**以你认证的个人或公司为准。软著著作权人、ICP 主办者都要与这个主体一致，不一致就要准备授权书（见第 6 节）。

## 2. 创建小游戏，拿到 AppID

1. 右上角点「控制台」→「小游戏」→「创建小游戏」。
2. 填写以下内容后勾选协议，点「创建」：
   - 小游戏开发引擎：选「其他」或「自研/原生 JS」，按页面实际选项选；
   - 小游戏名称：`拆封绘卷`。名称要求 4～20 个字符，且必须与软著登记名一致；
   - 联系人姓名、电话、邮箱。
3. 进入新建的小游戏，在「开发设置」（或总览页「开发者信息」）里能看到 **AppID**，格式一般是 `tt` 开头的一串字符。
4. 回到总览页「完善基础信息」，填写下面这些，然后「提交审核」：
   - 名称、图标、简介、详细介绍：现成文案在 `docs/store/商店简介.md`，图标可以用 `docs/store/icon_512.png`；
   - 类别、题材：建议选 休闲 → 益智 → 物理过关；
   - 软著（版号可以不填），并确认自审自查报告；
   - 基础信息由平台统一审核，审核中不能修改。
   - 官方说明：[创建与信息完善](https://developer.open-douyin.com/docs/resource/zh-CN/mini-game/guide/minigame/improve-information)
   - 填写规范：[小游戏基础信息审核规范](https://developer.open-douyin.com/docs/resource/zh-CN/mini-game/operation1/norms/game-info-audit)

## 3. 流量主 + 激励视频广告位（拿到广告位 ID）

1. 小游戏开发者后台 →「商业化」→「流量主」→ 申请开通。开通条件和收款信息以后台页面为准，通常要求小游戏已合法上线、资质齐全并通过平台审核。
2. 开通后进入「流量主」→「广告管理」→ 新建广告位，类型选**激励视频**，创建后会得到**广告位 ID**。
   - 官方说明（激励视频前提条件）：[激励视频广告](https://developer.open-douyin.com/docs/resource/zh-CN/mini-game/develop/api/c-api/ads/rewardedvideoad)
   - 接口说明：[tt.createRewardedVideoAd](https://developer.open-douyin.com/docs/resource/zh-CN/mini-game/develop/open-capacity/ads/tt-create-rewarded-video-ad)
3. 流量主通常要上线后才能开通，所以第一版**不填广告位 ID** 直接提审（保持 `YOUR_REWARDED_AD_UNIT_ID` 或留空都行）。这时游戏里：
   - 没有任何「看广告」按钮，也不会弹出假广告；
   - 失败面板的复活换成每关 1 次免费「再试一次」，效果同复活：多开一个孔、引信多烧 5 步，或送一次螺丝刀；
   - 道具用完后，每种道具每天可以免费领 1 个；
   - 不出现「多一个盒子（看广告）」的盒位。

   上线并开通流量主后，把广告位 ID 填进 `game-config.js`，上传新版本。复活和拿道具会自动恢复成激励视频，每关可看广告复活 2 次，第三个盒位也会回来。

## 4. 两个 ID 填在哪里

两个 ID 都填在工程根目录的 **`game-config.js`** 这一个文件里。用记事本或 VS Code 打开：

```js
module.exports = {
  appid: "YOUR_APPID",                          // ← 换成第 2 步拿到的 AppID
  rewardedAdUnitId: "YOUR_REWARDED_AD_UNIT_ID", // ← 换成第 3 步拿到的激励视频广告位 ID
  shareTemplateId: "",                          // 可选：分享素材审核通过后的模板 ID
};
```

- `rewardedAdUnitId` 保持 `YOUR_` 开头或留空，就当作「还没有广告位」：所有看广告入口都隐藏，改用免费再试一次和每日免费道具。
- 抖音开发者工具读的是 `project.config.json` 里的 `appid`。导入项目时工具会让你填 AppID，它会自动写进这个文件。你也可以手动把 `project.config.json` 里的 `"appid": "YOUR_APPID"` 改成同一个值。
- 如果你在源码工程里改（`douyin/douyin.config.json`），运行 `npm run build:douyin` 会把两个值同步到 `douyin/dist/` 的 `game-config.js` 和 `project.config.json`。

## 5. 导入抖音开发者工具、真机预览

1. 下载并安装**抖音开发者工具**（Windows 或 macOS 版）：[开发者工具](https://developer.open-douyin.com/docs/resource/zh-CN/mini-game/develop/dev-tools/mini-app-developer-instrument)
2. 打开工具，用开放平台账号扫码登录 →「导入项目」，目录选 `拆封绘卷\抖音小游戏\`，AppID 填你的 AppID。
3. 导入后模拟器应该直接显示「拆封绘卷」主界面。左上角礼包（侧边栏）在模拟器里也能点。工具 4.1.7 及以上可以模拟从侧边栏进入，场景值是 021036。
4. 点「预览」，用手机抖音扫码，在真机上玩一遍。重点检查这些：
   - 声音：音效、语音、音乐；
   - 第一次点屏幕后开始放音乐；
   - 过关后「分享通关录屏」。官方说明开发者工具不支持录屏调试，必须在真机上试；
   - 「看广告」按钮。
5. 侧边栏领奖的完整链路，官方建议在真机测试环境里跑通（详见官方指南「测试流程」）：[「必接」侧边栏复访能力技术指南](https://developer.open-douyin.com/docs/resource/zh-CN/mini-game/develop/guide/open-ability/Introduction-for-tech)

## 6. 上传、提审、备案、发布

1. 在开发者工具里点「上传」，填版本号 `1.2.0` 和更新日志。
2. 回到控制台 →「版本管理」：
   - 找到测试版本，扫码体验；
   - 确认没问题后「提交审核」，按要求上传 **3 张游戏内截图**，可以用 `docs/store/` 里的截图；
   - 首次上线要经过 QA 回归，官方说预计 1～3 个工作日；
   - 2026-04-20 起，提审会自动覆盖所有已接入抖音小游戏的合作 App；
   - 如果想灰度发布，**不要**勾选「自动发布」。
   - 官方说明：[版本提审指引](https://developer.open-douyin.com/docs/resource/zh-CN/mini-game/guide/minigame/examineguide)
3. **小游戏备案**（无版号）：基础信息审核通过、并且有版本提审通过后，平台自动申报，进度在「设置-基础设置-资质信息-小游戏备案申请」查看。注意：电子软著暂不能用于备案，要用国家版权局发的软著登记证书。
   - 官方说明：[小游戏备案申报](https://developer.open-douyin.com/docs/resource/zh-CN/mini-game/guide/minigame/game-filing-application-works)
4. **ICP 核准**：备案通过后入口开放，在「总览」或「设置-基础设置-游戏核准-ICP 核准」填写以下内容并上传附件：
   - 主办者信息、负责人信息；
   - 小游戏负责人信息，需要本人人脸核验；
   - 注意：个人主体的「应急电话」不能与手机号相同，部分省份有额外要求。
   - 官方说明：[ICP 核准指引](https://developer.open-douyin.com/docs/resource/zh-CN/mini-game/guide/minigame/icp/icp-filings)
5. ICP 核准号下来、版本审核通过后，在「版本管理」点「立即发布」（全量）或「灰度发布」。

## 7. 资质与合规细节

- **软著**：[小游戏资质规范](https://developer.open-douyin.com/docs/resource/zh-CN/mini-game/operation1/norms/credential-norms-for-mini-game)、[资质常见问题](https://developer.open-douyin.com/docs/resource/zh-CN/mini-game/guide/contactus/endowments)
  - 软件名称要与「拆封绘卷」一致，可以省略「游戏软件」等后缀；
  - 同一张软著只能用于一款在线小游戏；
  - 著作权人要与平台主体完全一致，否则需要授权书。企业授权书盖鲜章，个人授权书要手写签名、身份证号和手印；授权书剩余有效期要大于 3 个月。平台提供模板。
- **版号**：只有开通内购才需要。本游戏没有内购。将来要加内购，必须先取得版号，并接入客服能力。
- **隐私**：
  - 平台在小游戏页面统一展示隐私政策，名称和主体从后台带入，也就是你认证的真实主体，不是「狸猫」；
  - `docs/store/隐私协议.md` 里的「运营主体」「联系方式」都要填真实法律主体，「狸猫」只作出品署名；
  - 我们的补充说明见 `docs/store/隐私协议.md`；
  - 游戏本身不联网、不登录、不收集个人信息，只把进度存在本机（tt.setStorageSync）；
  - 广告、录屏分享都由抖音平台提供。
- **适龄提示**：[小游戏适龄提示分段表](https://developer.open-douyin.com/docs/resource/zh-CN/mini-game/operation1/norms/right-age)
  - 建议 **8+**，本游戏满足 8+ 的全部 6 条：
    - 没有陌生人自由交流的社交；
    - 卡通手绘画面；
    - 没有合作内容；
    - 背景简单友好；
    - 只有简单的思维判断；
    - 没有对抗战斗。
  - 申报入口：「设置-基础设置-小游戏适龄提示」。
- **侧边栏复访（必接）**：已按官方技术指南实现：
  - game.js 运行时同步监听 `tt.onShow`；
  - 用 `tt.checkScene({scene:'sidebar'})` 判断是否显示礼包；
  - 点礼包时读取 onShow 最新的 `launch_from === 'homepage' && location === 'sidebar_card'`（或场景值 021036）；
  - 按钮在「去首页侧边栏」（调用 `tt.navigateToScene`）和「立即领奖」之间切换；
  - 每天领一次：退一步、加孔、洗牌 各 1 个。
- **角色语音（VOICEVOX）**：游戏里（制作人员面板）和 `licenses/` 文件夹都已按各角色条款标注「VOICEVOX:名前」。2026-10-11 逐一打开官方规约页核对企业商用：
  - **四国めたん**（铆铆）、**東北きりたん**（苏枝）：[zunko.jp 音源利用ガイドライン](https://zunko.jp/con_ongen_kiyaku.html)
    - 商用、非商用都可以，需要署名；
    - 不区分个人和法人，没有事先联络的要求；
    - 不署名的商用要付费签约，本作已署名。
  - **春日部つむぎ**（小满）：[官方规约](https://tsumugi-official.studio.site/rule)
    - VOICEVOX 合成的音声商用、非商用都可以，需要署名，没有事先联络的要求；
    - 同页的「二次創作活動の手引き」要求企业在用**春日部つむぎ的角色形象**做二次创作前先联系。本作只用她的声音给原创角色配音，不使用她的形象。
  - **冥鳴ひまり**（阿蘅）：[官方规约](https://meimeihimari.wixsite.com/himari/terms-of-use) 写明「個人、法人問わずご利用いただけますので、申請や報告は必要ありません」。
  - v1.1 里铆铆用的 **猫使ビィ** 规约要求「企業による商用利用については、必ず事前にお問い合わせください」，猫使アル 同理。所以 v1.2.0 把铆铆的 6 句台词全部换成四国めたん重新合成，情绪参数不变。
  - 规约会更新，正式上架前请再打开上面的链接确认一遍。
- **分享素材**：
  - 被动分享（右上角菜单）用的图片，取自「开发者后台-运营能力-必接能力-分享配置」，可以先上传一张图，比如 `docs/store/` 的截图；
  - 录屏分享不需要额外配置；
  - 如果有审核通过的分享模板 ID，可以填到 `game-config.js` 的 `shareTemplateId`。

## 8. 工程结构与包体（v1.2.0 实测）

| 部分 | 内容 | 大小 | 官方上限 |
|---|---|---|---|
| 主包 | game.js、game-config.js、js/main.js（游戏代码，已打入 Matter.js）、11 张角色头像（pngquant 压缩）、49 个音效 mp3、licenses/ | 约 0.98 MB | 4 MB |
| 分包 voice | 36 句角色语音（mp3 64kbps 单声道） | 约 0.43 MB | 20 MB |
| 分包 bgm | 4 首循环曲 + 揭画短曲（mp3 96kbps，循环曲带首尾垫片，无缝循环） | 约 3.58 MB | 20 MB |
| 分包 cg | 3 幅插画（jpg） | 约 0.41 MB | 20 MB |
| 整包 | | 约 5.41 MB | 20 MB |

- 启动时先加载 cg 和 voice 两个分包（有进度条）。bgm 分包在后台加载，加载好就开始放音乐。
- **音频全部是 mp3**（抖音 iOS 不支持 ogg），构建时会自动检查，包里出现 ogg 或 wav 就报错。响度统一：
  - 语音约 -20.6 LUFS；
  - 音乐约 -22.4 LUFS；
  - 详见 `douyin/size-report.txt`。
- **背景音乐无缝循环**：mp3 文件头有编码器延迟、文件尾有补帧静音，直接 `loop=true` 时，循环点会有一小段空白。处理办法：
  - 构建时（`tools/douyin_bgm.py`）给每首循环曲加上前 0.5 秒、后 1 秒的首尾垫片；
  - 游戏里用两个音频实例接力播放（`src/systems/LoopTrack.js`）；
  - 解码检查和仿真测试都确认循环点没有空白，见 `douyin/bgm-loop-report.txt`、`npm run test:looptrack`。
  - 真机上请留意每首曲子 67～80 秒处的循环点。
- 分包规则：[tt.loadSubpackage](https://developer.open-douyin.com/docs/resource/zh-CN/mini-game/develop/api/subpackages/tt-loadsubpackage)

## 9. 常见问题

- **导入后黑屏**：在开发者工具「调试器」里看报错，确认 `project.config.json` 的 appid 已改成你的 AppID，基础库版本不要太低（游戏用到的接口最低需要 2.92.0，就是侧边栏接口）。
- **没有声音**：
  - iPhone 静音键打开时，InnerAudioContext 默认遵循静音开关，不会出声；
  - 音乐在第一次点屏幕后才开始放。
- **录屏分享提示没录到**：录屏要大于 3 秒，开发者工具不支持录屏，请在真机上试。
- **没有「看广告」按钮**：首发版没填广告位 ID 时就是这样，属于正常情况，见第 3 节。
- **广告不出来**：
  - 检查 `game-config.js` 的广告位 ID；
  - 检查流量主是否已开通、广告位是否启用；
  - 错误码 1004 可能是广告请求次数受限（官方说明需与广告投放沟通）；基础库 2.20+ 在 1004 时可能自动拉起分享，分享完成后 onClose 返回 count=1，游戏已按 count 判定发奖。
