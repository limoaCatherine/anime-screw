拆封绘卷 AnimeScrew v1.1.0 版本说明
==================================
出品：狸猫
日期：2026-10-11

怎么玩 (和 1.0 一样)
- 网页版：双击 dist/index.html
- Windows 桌面版：release/拆封绘卷/拆封绘卷.exe (整个文件夹一起拷走)
- 存档还在 %APPDATA%\AnimeScrew\save.json，1.0 的存档直接能用 (读的时候会自动检查、修正坏掉的字段)

这一版修了什么
【遮挡与点击】
- 被上层板子压着的螺丝绝对点不动了：包括晃过来、转过来的板子，以及正在往下掉、还没出画面的板子 (1.0 里板子刚开始掉的那一下，下面的螺丝就能点了)
- 手指下只有被压住的螺丝时，不会"顺手"拧到旁边的；会"咔"一声提示被挡住
- 同一个位置 0.2 秒内连点只算一次 (手抖双击不会把下面刚露出来的螺丝也拧掉)
- 螺丝在飞、板子在掉的时候连点别的螺丝：照常按规则处理，钉帽一个不丢
- 设置面板、失败面板、广告播放期间：点画面不会拧螺丝，物理和计时都暂停
- 复活按钮连点两下只看一次广告、只复活一次；看广告拿到的螺丝刀/小锤如果没用就取消，会存回道具栏

【判负】
- 螺丝在飞、盒子在换、板子还在动的时候不会判负；板子一直微微晃超过 5 秒也会照常判
- 真正的死局 (临时孔满了、能拧的螺丝一颗都进不了盒子) 一定会判负并弹出复活
- 绳吊板：剪断绳子会把整块板上的钉帽一次倒下来，放不下就不让剪 (提示"放不下")，不会再突然判负

【道具与可解性】
- 换盒 / 加孔 / 退一步 / 螺丝刀 / 小锤 / 复活之后，盒子队列都会按"场上还剩多少颗"自动对账：
  不会出现某种颜色没盒子可去、或者有盒子永远装不满。1.0 里第 15 关换盒后会卡死，已修
- 退一步会把板子位置角度、钉子、绳子、锁链、冰层、炸弹、盒子、临时孔全部还原；已经买的临时孔和第 3 盒位不会被退掉
- 复活清临时孔时不会清掉钥匙；钥匙钉帽没了的锁会自动打开 (不会出现永远打不开的锁)
- 冰冻螺丝的冰层不会多于周围剩下能拧的钉帽 (被锤子带走邻居后也一定敲得开)

【物理】
- 板子之间不碰撞 (1.0 起就是)，不会卡住；另外加了兜底：拧光的板子 4 秒内没出画面就直接移除
- 只剩一颗钉、而这颗钉正好在板子重心下方 ("倒立"在钉上) 时，会马上翻下来，不会顶着几秒再慢慢倒
- 小锤敲碎板子时有碎裂动画 (按板子轮廓裂成碎片带着贴图飞散)，玻璃板也一样

【障碍】
- 炸弹按"步数"倒数，暂停、面板、广告期间不会减少
- 每种新障碍第一次出现的那一关只有它自己：锁链 2-1、冰冻 2-3、钥匙锁 2-7、炸弹 3-1、隐色 3-2、绳吊 3-4、双层 3-7

【其他】
- 开场台词气泡挪到了画面最下方 (道具栏上)，不再挡住上面的螺丝；字幕跟着语音的长度走，开场闲聊等语音说完再出
- 网页版第一次点击就解锁声音 (手机上松手那一下也算)
- 存档体检：类型不对、数值越界、碎片和通关记录对不上，读取时自动修正
- 广告占位倒计时按真实时间算 (卡顿时不会变长)

语音 (全部重新录)
- 36 句 (原 27 句)，四个角色都改成更短、更口语的说法，加了 えっ / よしっ / もう～ / うそっ 这类语气词
- VOICEVOX 语速 1.12–1.25 倍、抑扬 1.15–1.5，句首句尾停顿缩短；按情绪选声线
  (铆铆=猫使ビィ：开心 ノーマル、安慰 おちつき、害羞 人見知り、着急 つよつよ；其他三位只有ノーマル，靠语调区分)
- 关键词单独抬高音调；部分句子句首轻轻吸一口气；加了很轻的小房间混响；响度统一 -20 LUFS
- 平均每句 1.97 秒 → 1.55 秒
- 每关最多说 2 句 (揭开整幅画那句除外)，同一场合每关只说一次；过关/连击/失败有 2~3 种说法轮换，最近 3 次说过的不重复
- 制作人员：VOICEVOX:猫使ビィ / 春日部つむぎ / 東北きりたん / 冥鳴ひまり

难度曲线
- 机器人 (只会"能进盒就进盒，不能就随便拧"的普通玩家) 每关打 96 局的通关率，1.0 → 1.1：
    (每行依次是第 1~10 关，单位 %；1.0 是 24 局，1.1 是 96 局)
    第1章  1.0: 100 100 100 100  96  88 100  96  75  71
          1.1: 100 100 100 100  84  91 100  89  89  89
    第2章  1.0: 100  92  67  50  63  88  63  79  42  58
          1.1:  89  88  93  78  73  84  76  65  66  68
    第3章  1.0:  71  71  46  42  46  75  54  46  29  79
          1.1:  73  86  74  72  59  81  65  64  64  79
    相邻两关最大落差：1.0 为 37 点 (2-8→2-9：79%→42%)，1.1 为 16 点 (3-6 放松关 81% → 3-7 双层螺丝 65%)；最低一关 1.0 为 29% (3-9)，1.1 为 59%
- 原则：相邻两关落差尽量不超过 ~12 个百分点；新障碍那关难度回落；每章一个小峰 (2-5 / 3-5 / 3-9 都可以看广告开第 3 个盒位)，峰后接放松关
- 机器人不会规划，真人一般会高一截

测试
- npm run verify：30 关 × 12 个随机种子重放参考解全部通过；新增遮挡独立复核、强制移除 0 次、钥匙/冰层数据、障碍首登检查
- npm run fuzz (新)：每关 24 局乱拧 + 随机用道具/复活，720 局全部正常结束，没有"死局不报"，退一步完全还原
- npm test：冒烟测试 + v1.1 回归 (连点、双击、点被压的螺丝、面板期间点击、复活连点、广告期间暂停、字幕位置、碎裂动画、坏存档)
- npm run test:play：浏览器里 30 关逐关通关；第 15 关打到一半换盒，照样通关
